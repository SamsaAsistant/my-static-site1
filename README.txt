САЙТ ДО ЛАБОРАТОРНОЇ РОБОТИ №2

Тема: Леонардо да Вінчі

Файли:
- index.html — головна сторінка
- biography.html — біографія
- paintings.html — картини
- inventions.html — винаходи
- legacy.html — спадщина

Виконані вимоги:
1. Багатосторінковий статичний HTML-сайт.
2. Головна сторінка має назву index.html.
3. На кожній сторінці є однакове верхнє меню <nav>.
4. Переходи виконуються локальними посиланнями через href.
5. Сайт можна відкривати без сервера.
6. Бонус: використано div-блоки для header, бокових колонок, основного вмісту та footer.
7. Для розподілу колонок використано display:flex та flex-grow.

Структура:
index.html
├── biography.html
├── paintings.html
├── inventions.html
└── legacy.html
